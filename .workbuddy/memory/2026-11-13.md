## 应用图标设计（朱印 / 墨页 / 简牍）

- 用户要求给当前 App 设计图标，并明确「通知提醒后续再运行」；本轮只做图标，未继续路线图。
- 复核现状：`AppScope` 与 `entry` 已有默认模板分层图标骨架（`layered_image.json` + background/foreground），`startIcon.png` 是蓝色四宫格模板图；`app.json5` / `module.json5` 的 `icon` 都指向 `$media:layered_image`，配置零改动。
- 查证官方规范：前景/背景均 1024² PNG；背景 RGB 纯色不透明、无圆角/内边距/文字；前景 RGBA 仅核心图形；系统自动套遮罩；**module.json5 的 icon 优先级高于 app.json5**，两套目录必须同步，否则上架审核以「未配置前景图/背景图」驳回。
- 三个方案，主推「朱印」：宣纸白底 + 朱红方印 + 白文「简」+ 细白内框；色值取自 `Theme.ets`（paper #F6F2E9 / cinnabar #B4432E / ink #1B1917）。备选「墨页」（纸页 + 横线 + 小印）、「简牍」（三片竹简 + 朱红编绳，取「简」字本义）。
- 对比 6 款中文字体后选 `STZHONGS.TTF`（华文中宋）：宋体横细竖粗最接近白文印且耐缩小。字形用 alpha 减法镂空（保留抗锯齿），并做轻微膨胀补偿小尺寸笔画；3× 超采样降采样出图。
- 新增 `design/generate_icon.py`（Pillow，仅构建期依赖，`--scheme seal|page|slips`），产出 `icon-preview.png`、`icon-full.png`、`icon-background/foreground.png`，并覆盖两套工程资源 + `startIcon.png`。
- 静态校验：背景 RGB 1024² 无 alpha；前景 RGBA 1024² alpha bbox `(199,199,825,825)` 居中留安全区；两套资源哈希一致；startIcon 152² RGBA 圆角。图标是 PNG 资源，**不受本机无 SDK 限制**，DevEco 打包即可生效。
