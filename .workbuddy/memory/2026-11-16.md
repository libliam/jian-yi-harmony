## 修复：回顾页补标标签切换无反应（用户 17:19 反馈）

- 现象：微光回顾页点维度标签没反应、选了新维度也不换；写库成功、无任何报错。这是微光一期**首次真机反馈** —— 说明 DB v1→v2 迁移、页面栈跳转、一步录入都能跑，坏的只有回顾页补标交互。
- 根因：`ForEach` 非首次渲染只按 key 判断能否复用组件，原 key 只有不变的 `row.id` / `group.date`。key 不变 → 复用旧组件 → itemBuilder 不重跑 → ① `if (this.editingId === row.id)` 不重新求值，补标面板压根不展开；② 标签文本仍是闭包里旧 `row.category`。与官方博客「数据改了、列表不刷新，而且一条报错都不产生」是同一个坑。`@State` 只观察第一层也救不了，换整个数组但 key 不变照样复用。
- 修法：`GrowthView` 加 `@State listVersion`，`load()` 结束与点标签展开/收起时递增；时间线内外层、维度分布、热力四处 ForEach 的 key 都带 `listVersion` 与展示字段（`categoryLabel(row.category)` / `item.count` / `count`）——展示字段进 key 是双保险；补标选项加当前维度深色高亮。`QuickSheet.miniChips` 同类问题一并修（key 从 `kind + opt` 改为带 `current`），否则录入弹层那排 chips 的选中态同样不变。
- 官方约束核对：keyGenerator 只允许读状态、不允许改组件状态；各 ForEach 的 itemGenerator / keyGenerator 是否声明 `index` 两边对称，避免框架自动拼 index。
- 文档：`AGENTS.md` 新增 3.7、能力清单微光行改为「真机已能运行，补标待复验」；`README.md` 进度表同步。
- **本机无 SDK，未编译验证**。真机复验：点标签应弹出七个维度且当前项高亮；选中后标签与「这段日子，长在哪儿」分布条同时变化；录入弹层里点维度 chips 选中态也要跟着变。

## 二次修复：补标不实时生效 + 应用内刷新入口（用户 17:32 反馈）

- 用户反馈：「切换标签，但是不是实时变过来，看着就像没效果，需要返回重新进入才能看到」；并问「在整个 app 页面，如何刷新这个页面」。
- **判定上一版修法不彻底**：把 `@State listVersion` 拼进 ForEach 的 keyGenerator 里读组件状态变量，不建立可靠依赖，框架未必重算 key。所以数据写进库了、`load()` 也重拉了，界面仍复用旧组件；只有返回重进触发首次渲染才显示新值 —— 与用户描述完全吻合。
- 正解：**keyGenerator 必须是纯函数，只读 item 自身字段；把变化信息编进数据源对象**。`GrowthItem { row, viewKey }` / `GrowthDayGroup { date, items, viewKey }`；`itemKey` 含 `id|categoryLabel|updatedAt|展开状态`（补标会写 `updated_at`，维度一改 key 必变），`group.viewKey` 汇总组内所有行 → 任一行变化整组换 key → 外层重建 → 内层拿到新数据。全部 keyGenerator 不再引用任何 `this.*`。
- `load()` 缓存 `allRows`；点标签时 `this.groups = this.makeGroups(this.allRows)` 同步重算、不读库，面板零延迟展开。`retag/remove` 改成先 `await load()` 再 `bumpRevision()`。维度分布 / 热力 / 补标选项的 key 改纯字段。
- 刷新机制答复：App 本来就有**全局自动刷新总线**（`bumpRevision()` → 各视图 `@StorageLink('dbRevision') @Watch('onRev')` 重拉；`Index.onPageShow` 回前台也 bump），正常无需手动刷新；这次是回顾页渲染 bug 造成「看着不刷新」。另加 ArkUI 原生 `Refresh` 下拉手势作显式入口：`$$this.refreshing` 双向绑定，`onRefreshing` 里 `load()` 完成复位、`.catch()` 也复位防止刷新头卡住。目前只在 `GrowthView` 落地，其余视图根组件结构不一（TodayView 是 Scroll，其它多为 List/自定义容器），推广留下一轮。
- 文档：`AGENTS.md` 3.7 补正解与纯函数约束、新增 3.8 刷新机制、速查表与能力清单；`README.md` 进度表 / 数据层说明 / 微光节。
- **本机无 SDK，未编译验证**。真机复验：点标签立即展开且当前维度高亮 → 选中后标签与分布条**当场**变化、不必返回重进 → 顶部下拉能触发刷新。
