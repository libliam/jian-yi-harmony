# 2026-11-19 · 真机打回：录入弹层 chips 全无反应 + 时间不能自选

## 用户真机反馈（业务提醒验证前置时发现）

- 录入弹层所有单选 chips（类型 / 标签 / 今天长期 / 优先级 / 心情 / 频率 / 时间）点按毫无反应，「感觉只是看的」；写库正常。
- 习惯 / 日程不能自选时间（原来只有 08:30/09:30/14:30/20:30 四个预设 chips），没法安排「几分钟后」的提醒，真机根本没法验证提醒。
- 新建待办不能选截止时间（固定 18:00 默认）；「不能编辑只能新建」——编辑 UI 是缺失功能，留待后续（P2 删除/编辑 UI 一起做）。

## 修复 1：@Builder 按值传参不刷新（`98ec53d`）

- 根因与修法已沉淀到 AGENTS.md 3.10：`miniChips(options, current, kind)` 三个独立参数按值传参，builder 永不重跑；改成 `interface ChipGroup` 单对象字面量（按引用传参）后正常。
- 3.7 的 ForEach key 修复是另一个独立坑，当时标「已修未复验」被真机打回——两条排查路径都要走。
- 全工程扫描过其余 @Builder：`TodoView.segButton`（builder 体内直接读 `this.pane`，安全）、`SearchPanel.highlighted`（参数为渲染时求值）、`timeWheel(target)`（静态字面量参数）都在安全路线上。

## 修复 2：时间选择改系统 TimePicker（`1ae36a5`）

- 习惯提醒时间 / 日程时间 / 今日待办截止时间三处换系统 `TimePicker` 滚轮（24 小时制，纸墨配色 textStyle），预设 chips 退役。
- 待办截止默认 18:00；习惯默认 09:30。选完即可安排「当前 +3 分钟」的提醒，真机验证提醒不再需要调系统时间。
- 表单内容区包了一层 `Scroll`（constraintSize maxHeight 480），滚轮把表单撑高时保存按钮不会被截断。
- 每周习惯显示「暂不发提醒」提示；日程表单显示日期行（`uiPlanDate` 目前无人写入，恒为今天）。
