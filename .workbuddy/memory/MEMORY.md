# 项目长期记忆 · 简忆（JIAN YI）

## 用户明确的产品原则（2026-11-12）

- 这是**要装到手机上的 HarmonyOS 原生 App**，不是网页、不是 WebView 套壳。
- **系统级操作必须按原生规范实现**：系统返回键/侧滑返回、页面与 Ability 生命周期、前后台、状态栏与安全区、权限、通知、备份。不能只在界面画一个自绘按钮就算完成。
- 导航要有**真实页面栈**，让系统返回自然逐层回退。2026-11-13 已用独立 `@Entry` 页面 + router 系统页面栈落地（搜索页 / 二级页）；单页条件渲染覆盖层已退役，后续可迁移官方推荐的 `Navigation`。
- `jianyi-prototype.html` 只是交互原型与设计事实来源，禁止作为运行时 UI。
- 判断标准：断网可用、清后台再进数据还在、按系统返回逐层退、切换深浅色不闪黑 —— 行为像系统应用，不像浏览器标签页。

## 工作约束

- 本机没有 HarmonyOS SDK / hvigorw，ArkTS 代码**无法在本会话编译**；由用户在 DevEco Studio 5.0+ 编译并在真机预览。改动后必须标注「未编译验证」。
- 用户会在 DevEco Studio 里手动改代码（已发生过一次），**改文件前必须重新读取磁盘内容**，不要凭记忆 Edit。
- 长期约定以 `.trae/rules/project_rules.md` 为准；Agent 速查、系统能力清单与踩坑记录在项目根 `AGENTS.md`。
- 应用名统一「简忆」；UUID 主键、软删除、派生数据现算；页面不出现 SQL；色彩只从 `common/Theme.ets` 取。
